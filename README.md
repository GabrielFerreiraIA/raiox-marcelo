# Raio-X Imohills

App pós-diagnóstico da Multiplix, preparado para Marcelo Coimbra. Produção estática, sem dependências.

## Rodar

Abra `index.html` ou execute `python -m http.server 8080 --bind 127.0.0.1 --directory raiox-imohills` a partir da pasta pai. Código de apresentação `marcelo123`.

O código é validado no frontend e dura enquanto a aba estiver aberta. É uma barreira de apresentação. Os arquivos são públicos em hospedagem estática.

## Publicação

Na Vercel, use a raiz desta pasta, preset **Other**, sem instalação ou build, com saída `.`. Para Vercel Drop, entregue o ZIP com `index.html` na raiz. Confira o endereço final em uma sessão anônima, o login e o vídeo antes de encaminhar.
